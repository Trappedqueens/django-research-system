1. 只输出【数据库设计 + 后端代码 + 前端代码】

3. 代码要完整、规范、可运行（不是伪代码）

====================

一、系统功能模块

====================



1. 用户模块

- 角色：管理员 / 教师 / 专家

3. 项目审核模块

- 专家审核项目

- 审核意见

- 审核时间



4. 项目管理模块

- 管理员查看所有项目

- 查询 / 分页 / 状态筛选

====================
